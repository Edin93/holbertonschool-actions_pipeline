## Learning Objectives

- What is CI/CD and why it matters in software development
- What is GitHub Actions and how it fits in the CI/CD landscape
- What are workflows, jobs, steps, and how they relate to each other
- How to trigger workflows on push, pull request, manual dispatch, and schedule
- How to set up a Node.js environment in a CI runner
- How to automate test execution and fail a workflow on test failure
- How to enforce code quality with linting and formatting in CI
- How to use job dependencies to control execution order
- How to build artifacts and pass them between jobs
- How to build and push Docker images to a container registry in CI
- How to use GitHub environments and branch protection for deployment gates
- How to use matrix strategy to test across multiple versions or operating systems
- How to cache dependencies to speed up workflow runs
- How to write to job summaries and open issues from a workflow
- How to create a reusable composite action to eliminate repeated steps
- How to pass data between jobs using job outputs and $GITHUB_OUTPUT
- How to run jobs in parallel across multiple OS runners
- How to schedule workflows with cron syntax
